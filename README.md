# Mes outils de classe

Page d'accueil qui regroupe tous mes outils pédagogiques : https://anlito.github.io/

Elle est mise en ligne automatiquement par GitHub Pages à chaque envoi sur la branche `main`.

## Ajouter un nouvel outil

Dans `index.html`, copier un bloc `<article class="tool">…</article>`, puis changer :
le nom, la description, le lien « Ouvrir l'outil », le lien de « Copier le lien », l'adresse affichée et les documents.
Mettre aussi à jour le compteur « N outils en ligne » en haut de la page.
